# SolarisPKN Video Publisher

Low-volume local editor for one long video plus one vertical short. Double-click `abrir-publicador-video.cmd`, upload both edited files, adapt metadata, review the SHA-256 plan, and explicitly type `PUBLICAR VIDEO` before any configured official API is called.

The Spanish [README.es.md](README.es.md) contains the complete usage, credential, safety, and platform notes.
